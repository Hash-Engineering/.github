## About Hash

We investigate technical problems and build software around what we learn. Our work brings together software development, applied AI, and engineering education, with an emphasis on testing, reproducibility, and clear technical decisions.

## Areas of work

- **Software systems:** backend services, APIs, Python applications, and developer tools.
- **Applied AI and data:** data workflows, machine learning experiments, evaluation, and integration into software systems.
- **Engineering practice:** automated testing, reliability, technical documentation, and review workflows.

## How we work

We start with the problem, define what success would look like, and make the evidence reviewable.

That means small changes, explicit trade-offs, tests that check meaningful behaviour, and documentation that explains both results and limitations. Code review is part of the work, not a final formality.

## Hash Engineering Fellowship

Our remote, project-based fellowship gives emerging engineers a structured setting to build and review individual projects in **Software Engineering** and **Applied AI & Data**.

Each project follows a brief and milestone plan. Fellows use GitHub issues, branches, and pull requests to develop their work, run automated checks, document decisions, and respond to written review feedback.

Fellowship work may remain private. Projects are published or featured with the fellow's permission.
