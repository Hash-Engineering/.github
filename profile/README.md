# Hash Engineering

Hash Engineering is an applied software engineering studio based in Indonesia. We build practical software systems and create structured technical learning opportunities for emerging engineers.

## What we work on

Our work and technical interests include:

- Backend systems and APIs
- Python applications and developer tooling
- Applied AI and data systems
- Testing, reliability, and engineering workflows
- Technical research and engineering education

## Hash Engineering Fellowship

The Hash Engineering Fellowship is a remote, project-based learning program where fellows build individual technical projects through professional GitHub workflows.

Fellows work with:

- Individual project briefs and milestones
- Issues, branches, and pull requests
- Automated testing and continuous integration
- Technical documentation and decision records
- Structured code review and written feedback

Fellowship repositories remain private while active. Completed projects may be published or featured with each fellow’s permission.

## How we work

We value clear problem definitions, small reviewable changes, reproducible results, honest documentation, and engineering decisions supported by evidence.
